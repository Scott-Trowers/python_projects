# day 10 - beach dash

A classic "frogger" style game where the player must guide a baby turtle across a beach full of scuttling crabs to the safety of the sea.

## how to run

```bash
uv run src/main.py
```

## skills

- object-oriented programming with multiple decoupled modules
- game loop mechanics and timing/refresh management
- collision detection and progressive difficulty scaling

## features

- classic frogger gameplay guiding a baby turtle to the ocean
- dodge randomly spawned crabs moving horizontally across the beach
- responsive keyboard controls (W, S, A, D)
- progressive difficulty increasing crab spawn rate and speed as turtle level increases
- final score summary displayed upon game over
