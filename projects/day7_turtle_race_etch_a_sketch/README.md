# day 7 - turtle race and etch-a-sketch

A project showcasing two interactive applications built with Python's `turtle` library: a turtle racing game and a free-form Etch-a-Sketch style drawing program.

## how to run

```bash
uv run src/main.py
```

## skills

- turtle graphics for creating dynamic visual displays
- event listeners for interactive keyboard controls (`turtle.onkey`)
- managing multiple active turtle instances simultaneously
- random speed simulation and finish-line detection

## features

- interactive betting on one of four turtle contestants
- each turtle advances at a random speed making each race unpredictable
- tracks finish line order and displays winners on a podium
- free-form drawing application controlled entirely by keyboard inputs (A/D to move, Left/Right arrow keys to turn, Space to toggle pen, C to clear)
