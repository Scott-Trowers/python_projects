# day 2 - higher or lower

A CLI guessing game based on Instagram follower counts. Pick which of two celebrities or brands has more followers and build a streak.

## how to run

```bash
uv run src/main.py
```

## features

- random pairs drawn from a dataset of ~50 celebrities and brands
- streak-based scoring — one wrong answer ends the round
- tracks session stats: games played, highest streak, lowest score, and total score
