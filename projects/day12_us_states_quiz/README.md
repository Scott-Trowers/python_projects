# day 12 - us states quiz

A quiz game that tests your knowledge of US states by having you name them one by one.

## how to run

```bash
uv run src/main.py
```

## skills

- `turtle` for the GUI and drawing
- `pandas` for reading and processing CSV data
- classes to represent states on the map
- loops and conditional logic for the game flow

## features

- guess the 50 US states in a pop-up dialog
- correctly guessed states are displayed on a map of the USA
- the game tracks your score as you guess more states
- a message is displayed when all 50 states have been correctly named
