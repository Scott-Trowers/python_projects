# day 9 - classic pong game

A recreation of the classic arcade game "Pong," built with Python's `turtle` library using an object-oriented approach.

## how to run

```bash
uv run src/main.py
```

## skills

- object-oriented design with decoupled classes (`PongPaddle`, `PongBall`, `ScoreBoard`)
- coordinate geometry and movement mechanics for ball physics
- game state management, multi-player controls, and collision boundaries

## features

- classic Pong two-player action with intuitive controls (W/S for Player 1, Up/Down for Player 2)
- dynamic ball physics with realistic bouncing off walls and paddles
- real-time score tracking and custom scoreboard display
- game automatically ends when a player reaches the winning score
