# day 8 - classic snake game

A recreation of the classic arcade game "Snake," built with Python's `turtle` library.

## how to run

```bash
uv run src/snake.py
```

## skills

- object-oriented design and game loop architecture
- turtle-based responsive controls and collision detection
- game state management (difficulty levels, dynamic body growth, game boundaries)

## features

- classic snake gameplay with responsive controls (W, A, S, D keys)
- interactive difficulty settings (Easy, Medium, Hard) that control snake speed
- dynamic growth as snake consumes food
- boundary and self-collision detection with real-time score tracking
- contains both a modern object-oriented version and a legacy procedural version
