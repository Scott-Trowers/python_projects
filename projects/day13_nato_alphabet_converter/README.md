# day 13 - nato alphabet converter

A CLI tool that converts any input text into its corresponding NATO phonetic alphabet spelling.

## how to run

```bash
uv run src/main.py
```

## skills

- `pandas` for reading and processing CSV data
- dictionary comprehensions and mapping values
- list comprehensions for text parsing and nested structures

## features

- loads phonetic data from a CSV dataset
- prompt-driven user input for words or phrases
- dynamic conversion of characters into NATO phonetic codes
- clean, structured multi-line output representing each word's phonetic translation
